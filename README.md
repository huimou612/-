# 存储世家隐私政策

**更新日期：** 2025年4月30日  
**生效日期：** 2025年4月30日  
**版本号：** v1.0

---

## 一、引言

存储世家（以下简称"本应用"）由存储世家团队开发运营。我们深知个人信息对您的重要性，将竭尽全力保护您的信息安全。本隐私政策旨在向您清晰说明我们如何收集、使用、存储和保护您的信息。请您在使用本应用前仔细阅读并充分理解本政策。

---

## 二、信息收集范围

### 2.1 设备信息
- 设备型号、操作系统版本
- 屏幕分辨率、设备语言设置
- **收集目的：** 用于优化应用界面适配、诊断兼容性问题

### 2.2 权限使用说明

| 权限名称 | 权限类型 | 使用场景 | 是否必须 |
|---------|---------|---------|---------|
| 相机权限 | 敏感权限 | 条码扫描、商品拍照 | 否（核心功能可用） |
| 存储权限 | 敏感权限 | 保存/读取商品照片 | 否 |
| 振动权限 | 普通权限 | 扫码成功反馈 | 是 |
| 网络权限 | 普通权限 | 加载网络图片资源 | 是 |

### 2.3 业务数据
- 商品名称、SN序列号、分类信息
- 回收价格、运费、服务费、销售价格
- 商品照片文件路径
- 入库/出库时间记录
- **重要说明：** 以上所有业务数据**仅保存在您的设备本地**，我们不会以任何形式收集或上传这些数据。

### 2.4 不收集的信息
本应用**明确不收集**以下内容：
- 个人身份信息（姓名、身份证号、手机号）
- 地理位置信息
- 通讯录、短信等个人隐私数据
- 账号密码信息

---

## 三、信息使用方式

我们收集的信息仅用于以下目的：

1. **提供核心功能：** 库存管理、出入库记录、数据统计
2. **优化用户体验：** 根据设备特性调整界面显示
3. **故障诊断：** 收集崩溃日志以修复应用问题（仅收集错误堆栈，不含业务数据）
4. **功能改进：** 分析功能使用频率以优化产品方向

---

## 四、数据存储与安全

### 4.1 本地存储
- 所有库存数据、订单记录存储在设备本地数据库（SharedPreferences + 本地文件系统）
- 商品照片存储在应用私有目录或用户选择的相册位置
- **数据不上传云端，不经过任何网络传输**

### 4.2 安全措施
- 应用已关闭Android系统级自动备份（`android:allowBackup="false"`）
- 应用数据受Android系统沙箱机制保护，其他应用无法访问
- 定期更新依赖库以修复安全漏洞

### 4.3 数据保留与删除
- 数据保留期限：自创建之日起至应用卸载为止
- 卸载应用后，所有本地数据将被Android系统清除
- 用户可随时在应用内删除单条记录

## 五、用户权利

您拥有以下权利：

| 权利 | 操作方式 |
|-----|---------|
| 查看数据 | 在"记录管理"页面查看所有历史记录 |
| 修改数据 | 点击记录卡片编辑备注信息 |
| 删除数据 | 左滑记录项或点击删除按钮 |
| 导出数据 | 后续版本将支持数据导出功能 |
| 撤销操作 | 出库记录支持"撤销出库"恢复库存状态 |
| 卸载清除 | 卸载应用即可清除所有数据 |

## 七、儿童隐私保护

本应用不面向14周岁以下儿童提供服务。如果您发现儿童在使用本应用，请立即联系我们，我们将采取措施删除相关数据。
